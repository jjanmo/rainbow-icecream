# ADR-0006: 보유 종목 페이지는 읽기 전용 테이블 + 모달 편집

## Status
Accepted

## Context
초기 보유 종목 테이블은 인라인 편집이 가능했다. 그러나 실시간 시세 갱신으로 테이블이 주기적으로 리렌더되는 상황에서 인라인 입력 상태를 유지하는 것이 사용성/구현 복잡도 양쪽에서 불리했고, 사용자도 "기본은 읽기 전용, 편집은 별도 동작"을 선호했다.

## Decision
`/holdings`는 읽기 전용 테이블로 렌더링하고, 추가/수정은 별도 모달(`HoldingFormDialog`)에서 처리한다. 필수 입력값은 시각적으로 구분 표시한다.

## Consequences
- 실시간 가격 갱신이 편집 중인 입력을 방해하지 않는다.
- 편집이 명시적인 사용자 액션(모달 열기)을 거쳐야 하므로 실수로 값이 바뀔 가능성이 낮다.
- 목록에서 바로 값을 스치듯 고칠 수는 없다 — 항상 모달을 거쳐야 한다.
