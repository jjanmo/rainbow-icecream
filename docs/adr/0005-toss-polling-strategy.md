# ADR-0005: Toss 시세 연동 — 1분 폴링 + 적응형 백오프, WebSocket 미사용

## Status
Accepted

## Context
Toss 증권 Open API는 WebSocket을 지원하지 않고("추후 지원 예정"), 레이트리밋 한도가 공식 문서에 명시돼 있지 않아 응답 헤더로만 유추할 수 있다. 또한 모든 응답이 공식 문서에 없는 `{"result": ...}` 래퍼로 감싸져 오는 것을 실제 API 호출로 확인했다.

## Decision
가격/환율을 1분 기본 간격으로 폴링하고, 레이트리밋 관련 응답 헤더를 관찰해 필요 시 폴링 간격을 늘리는 적응형 백오프를 적용한다. 모든 Toss 응답 스키마는 `.result`를 언래핑하도록 작성한다.

## Consequences
- 진짜 실시간은 아니고 최대 1분 지연이 있을 수 있다.
- 레이트리밋을 공식적으로 알 수 없으므로 하드코딩된 한도가 아니라 관찰된 신호에 반응하는 방식이라, Toss 쪽 정책이 바뀌면 재조정이 필요할 수 있다.
- Toss가 문서를 갱신하지 않는 한, 실제 동작은 항상 직접 curl 등으로 검증해야 신뢰할 수 있다.
