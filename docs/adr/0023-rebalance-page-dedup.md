# ADR-0023: 비중 체크 페이지에서 설정/보유종목 페이지와 중복되는 내용 제거

## Status
Superseded by ADR-0056 (비중 체크 페이지 자체가 없어지고 포트폴리오 화면에 흡수됨) — 이 문서가 정리했던 "무엇을 중복 제거했는가"의 기록은 그대로 남긴다.

## Context
`/rebalance`("비중 체크")가 시간이 지나며 다른 페이지와 같은 숫자를 여러 형태로 반복해서 보여주게 됐다:
- 상단 총 평가금액 카드 → `/setup` 읽기 모드 "실제 보유 비중" 도넛의 배지와 동일한 값.
- 상단 자산군 간 목표/실제 비중 도넛 2개 → `/setup` 읽기 모드 상단 도넛 2개와 값·구성이 동일.
- 자산군별 목표/실제 막대(전체 포트폴리오 기준) → 위 도넛과 같은 숫자를 막대로만 다시 그린 것.
- 종목별 "그룹내 실제 %" → `/setup`을 자산군을 펼쳤을 때 `GroupHoldingsPanel`(파이+리스트)이 이미 보여주는 값과 동일(ADR-0021).

같은 정보를 페이지마다 다른 그래프로 반복해서 보여줄 이유가 없어, 이 페이지에만 있는 내용(괴리, 리밸런싱 필요 여부/조치 금액, 종목의 전체 포트폴리오 기준 목표·실제 비중, 자산군 내 목표 비중)만 남기기로 했다.

## Decision
- `StatCards`: "총 평가금액" 카드 제거. "리밸런싱 필요 종목/자산군" 카드만 유지.
- 상단 자산군 간 목표/실제 비중 도넛 2개(`AllocationDonutChart`) 페이지에서 완전히 제거.
- `GroupProgressBar`: 자산군 전체(목표/실제) 막대 제거, 자산군 이름+색 점만 종목 목록의 헤더로 유지.
- `HoldingProgressBar`: "그룹내 실제 %" 막대/텍스트 제거. "그룹내 목표 %"(`targetPctInGroup`)만 유지 — 이 값은 다른 어느 페이지에도 없다.
- `RebalanceTable`은 그대로 둔다 — 전체목표%/전체실제%/차이/조치 필요액 모두 이 페이지에만 있는, 종목 단위 전체 포트폴리오 기준 계산값이다. 종목명/자산군 열은 그 값들을 식별하기 위한 라벨이라 중복 제거 대상으로 보지 않았다.

## Consequences
- 페이지가 훨씬 짧아졌고, 같은 숫자를 여러 화면에서 서로 다른 값처럼(반올림 자릿수가 다르거나 그래프 형태가 달라) 헷갈릴 여지가 줄었다.
- "그룹내 목표 %"는 현재 입력 UI가 없어(ADR-0018로 설정 페이지에서 그룹 내 비중 편집이 제거됨) 신규 종목은 대부분 0%로 보인다 — 그래도 다른 페이지에 없는 유일한 값이라 이번 정리에서는 남겨뒀다. 이 값 자체가 더는 의미가 없다고 판단되면 별도로 제거를 논의해야 한다.
- 페이지 설명 문구와 섹션 제목(`pages/rebalance.tsx`)도 "괴리/조치 중심"으로 다시 썼다.
