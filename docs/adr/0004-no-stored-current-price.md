# ADR-0004: 현재가는 절대 저장하지 않고 항상 읽는 시점에 라이브로 계산

## Status
Accepted

## Context
초기 스키마에는 `holdings.current_price`/`price_updated_at` 컬럼이 있었다. 그러나 현재가는 본질적으로 매 순간 바뀌는 값이라, DB에 저장하면 갱신 로직과 staleness 문제가 함께 생긴다.

## Decision
`current_price`/`price_updated_at` 컬럼을 스키마에서 제거한다. 현재가는 항상 읽는 시점에 Toss 라이브 시세로 계산하며, 시세가 없는 종목(티커 없음, 조회 실패)은 평균매입가를 대체값으로 쓴다. 이 계산은 한 곳(포트폴리오 평가 로직)에서만 수행한다.

## Consequences
- DB에 가격 관련 stale 데이터가 존재할 수 없다.
- 평가금액이 필요한 모든 화면은 같은 라이브 시세 파이프라인(가격/환율 폴링)을 거쳐야 한다.
- 오프라인이거나 Toss 조회가 실패하는 동안은 평균매입가 기준으로 표시된다 — "현재가"가 아니라는 걸 사용자가 오해하지 않도록 UI에서 구분할 필요가 있다.
