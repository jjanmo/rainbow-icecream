# ADR-0018: 설정 페이지 UI에서 그룹 내 비중 편집/표시를 제거

## Status
Accepted

## Context
설정 페이지는 지금까지 자산군 비중(`targetPct`)과 그룹 내 종목 비중(`targetPctInGroup`)을 함께 편집하도록 만들어져 왔다(ADR-0007, ADR-0010, ADR-0013, ADR-0017 등). 그런데 이 페이지가 다뤄야 할 핵심은 자산군 단위 배분이고, 종목 단위 그룹 내 비중은 화면과 로직을 계속 복잡하게 만드는 요소였다 — 그룹 내 합계 경고, "환산 시" 문구, 종목별 그룹 내 비중 인라인 입력 등.

**범위를 명확히 하기 위해 사용자에게 직접 확인**: 이 변경은 **설정 페이지 UI에서만** 그룹 내 비중을 없애는 것이고, `targetPctInGroup` 개념 자체(도메인 타입, DB 컬럼, 비중 체크 페이지의 종목별 목표%/차이/조치 필요액 계산)는 그대로 유지한다. 비중 체크 페이지는 이 변경의 영향을 받지 않는다.

## Decision
- `GroupCard`/`EditGroupCard`에서 "그룹내 X% 부족/초과", "환산 시 ..." 경고 문구를 전부 제거했다. 자산군 카드는 이제 자산군 자체의 목표 비중(`targetPct`)만 보여주고 편집한다.
- `EditHoldingInlineRow`/`HoldingInlineRow`에서 종목별 비중 관련 텍스트(편집 가능한 "그룹 내 X%"와, 한 차례 다시 넣었다가 결국 뺀 읽기 전용 "전체의 Y%" 둘 다)를 전부 제거했다. 이 두 컴포넌트는 이제 티커/종목명만 보여준다 — `targetPctInGroup` 기반 숫자는 설정 페이지 어디에도 노출하지 않는다.
- `targetPctInGroup`은 이제 설정 페이지 어디에서도 편집할 수 없다 — 새로 추가한 종목은 0으로 고정되고, 기존 종목은 마지막으로 저장된 값을 그대로 유지한 채 더는 바뀌지 않는다.

## Consequences
- 설정 페이지가 순수하게 "자산군끼리 비중을 어떻게 나눌지"만 다루는 화면이 됐다 — ADR-0017(자산군 카드 접기)의 취지가 한 단계 더 강화된 셈이다.
- 비중 체크 페이지의 종목별 목표%(`group.targetPct × holding.targetPctInGroup / 100`)와 "리밸런싱 필요 종목" 카드는 그대로 살아있지만, 그 기준이 되는 `targetPctInGroup`을 갱신할 방법이 앱 어디에도 없다 — 사실상 동결된 값이다. 이후 실제로 종목 단위 목표를 다시 조정할 수 있어야 한다면, 별도 화면이나 이 기능의 부활이 필요하다.
- `lib/setupDraft.ts`의 `commitSetupDraft`는 `targetPctInGroup` 변경분도 여전히 diff해서 반영하는 로직을 갖고 있다(코드는 안 건드림) — 어차피 UI에서 바뀔 일이 없어 실질적으로 no-op이 된다.
