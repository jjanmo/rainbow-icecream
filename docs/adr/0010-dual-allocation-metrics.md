# ADR-0010: 설정 페이지 상단에 "목표 배분"과 "실제 채워짐" 두 지표를 분리 표시

## Status
Accepted

## Context
단일 지표("전체 목표 비중 합계" = 각 자산군 목표%의 합)만 보여줄 경우, 자산군 레벨 배분은 100%를 채웠어도 특정 자산군 내부에서 종목 배분이 덜 끝난 상태를 구분할 수 없었다 — 상단은 "정상"으로 보이는데 실제로는 종목까지 다 배정되지 않은 상황이 가능했다. 또한 자산군 카드에 그룹내 괴리와 전체 환산 괴리를 나열식으로 같이 보여주니 "두 수치를 더하면 상단 값과 맞아야 한다"는 오해를 줄 수 있었다.

## Decision
상단 요약에 "목표 배분"(자산군 목표% 합)과 "실제 채워짐"(자산군 목표% × 그룹내 종목비중합계/100의 합) 두 개의 독립된 바/배지를 보여준다. 각 자산군 카드에서도 그룹내 상태와 전체의 목표%를 항상 같이 노출하고, 그룹내 괴리를 전체 스케일로 환산한 값은 "환산 시" 괄호로 종속 표기해 별개의 합산 대상이 아님을 명시한다.

## Consequences
- 사용자가 "자산군 배분은 끝났는데 종목 배분만 남았다"는 상태를 한눈에 구분할 수 있다.
- 화면에 이해해야 할 숫자가 하나에서 둘로 늘었다 — 레이블과 배지로 각 숫자의 의미를 명확히 구분해야 혼란을 막을 수 있다.
