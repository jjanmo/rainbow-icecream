# ADR-0008: 리밸런싱 기준 5%p, 통계 카드는 기준 초과 항목만 표시

## Status
Superseded by ADR-0026 (기준값 5%p → 10%p, 색상 규칙 분리)

## Context
초기 리밸런싱 기준(threshold)은 1.5%p로, 거의 모든 종목/자산군이 리밸런싱 필요로 표시될 만큼 민감했다. 또한 기존 "괴리 최대 자산군" 카드는 기준 충족 여부와 무관하게 항상 괴리 1위 자산군을 보여줬는데, 이는 업계에서 일반적으로 쓰는 방식이 아니라는 지적이 있었다.

## Decision
`REBALANCE_THRESHOLD`를 5%p로 상향한다. "리밸런싱 필요 종목"/"리밸런싱 필요 자산군" 두 통계 카드 모두 이 기준을 넘는 항목만 개수+이름으로 나열하는 방식으로 통일한다.

## Consequences
- 실제로 조치가 필요한 수준의 괴리만 강조되어 노이즈가 줄어든다.
- 종목 레벨과 자산군 레벨이 동일한 "필요/불필요" 판단 기준을 공유한다.
- 기준값이 하드코딩돼 있어, 사용자별로 다르게 조절하려면 별도 설정 기능이 필요하다 (PRD의 열린 질문 참고).
