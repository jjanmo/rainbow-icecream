# ADR-0003: 매직링크 대신 이메일+비밀번호 인증

## Status
Accepted

## Context
초기 구현은 매직링크(OTP) 로그인을 사용했다. 그러나 이 앱은 관리자가 유저를 직접 생성해주는 소규모/개인용 앱이라, 셀프서비스 온보딩보다는 단순한 로그인 흐름이 더 적합했다.

## Decision
Supabase 이메일+비밀번호 인증으로 전환한다. 관리자가 Supabase 대시보드에서 유저 계정과 비밀번호를 직접 생성한다.

## Consequences
- 회원가입 화면/플로우가 필요 없다 — 로그인 화면만 있으면 된다.
- 신규 유저 추가는 항상 수동(관리자) 작업이다.
