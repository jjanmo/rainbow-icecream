# ADR-0017: 자산군 카드는 기본적으로 접힌 상태, 클릭해야 종목 목록/그룹 내 비중을 볼 수 있음

## Status
Accepted

## Context
설정 페이지는 항상 모든 자산군의 종목 목록을 펼쳐서 보여줬다. 그런데 이 페이지가 우선 다뤄야 하는 건 "자산군끼리의 비중"이고, "자산군 안에서 종목끼리의 비중"은 그 다음 단계의 세부사항이다. 두 레벨이 한 화면에 항상 같이 노출되니 자산군 목록 자체를 한눈에 훑어보기 어려웠다.

## Decision
읽기 모드(`GroupCard`)와 편집 모드(`EditGroupCard`) 둘 다 종목 목록을 기본적으로 접어두고, 자산군 카드의 화살표(읽기 모드는 헤더 전체, 편집 모드는 별도 화살표 버튼 — 헤더에 이름/비중 입력 등 다른 상호작용 요소가 있어 헤더 전체를 버튼으로 묶을 수 없음)를 클릭해야 펼쳐지도록 바꿨다. 접힌 상태에서도 "그룹내 X% · 전체의 Y%" 요약 텍스트는 그대로 보여서, 종목 단위까지 안 열어봐도 이 자산군이 정상인지 경고 상태인지는 바로 알 수 있다. 펼쳤을 때 보이는 내용(종목별 그룹 내 비중 인라인 편집, 드래그 순서 변경, 종목 추가 버튼)은 이전과 동일 — 기능을 없앤 게 아니라 기본 노출 여부만 바꿨다.

## Consequences
- 자산군이 많은 포트폴리오에서도 상단 목록이 한눈에 들어온다.
- 종목 비중을 확인/수정하려면 반드시 한 번의 클릭이 추가로 필요하다.
- 펼침 상태는 컴포넌트 로컬 상태라 페이지를 벗어나거나 편집모드를 나가면 초기화된다 — 여러 자산군을 동시에 열어둔 상태를 기억해두지 않는다.
