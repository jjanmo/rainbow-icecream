# ADR-0016: 자산군 목표 비중 합계가 100%를 초과하면 완료를 막는다

## Status
Superseded by ADR-0037 (100% 미만도 완료를 막는 것으로 변경)

## Context
설정 페이지의 `AllocationBar`는 자산군 목표 비중 합계(`targetSum`)가 100%를 넘으면 막대가 카드 밖으로 흘러넘치는 렌더링 버그가 있었다(폭 %가 그대로 flex item width로 들어가 컨테이너를 벗어남). 이를 고치면서, 100% 초과는 단순히 "아직 덜 채운" 미완성 상태(100% 미만)와는 성격이 다르다는 논의가 있었다 — 미만은 UI로 얼마든지 표현 가능한 정상적인 중간 상태지만, 초과는애초에 성립할 수 없는 값(전체의 100%보다 많은 비중을 자산군에 배정하는 것)이라 실질적으로 오류다.

## Decision
- `AllocationBar`는 합계가 100%를 넘으면 각 세그먼트를 비율대로 축소해서 항상 바 안에 맞게 그린다. 라벨/툴팁은 축소 전의 실제 값을 그대로 보여준다. 상단 요약 배지 문구도 초과/미만을 구분해서 "100%보다 X% 초과" / "100%까지 X% 남음"으로 갈렸다.
- 설정 페이지 편집 모드에서 draft 자산군들의 목표 비중 합계가 100%를 초과하면 "완료" 버튼을 비활성화하고, 이유를 알려주는 문구를 버튼 옆에 띄운다. **100% 미만인 경우는 막지 않는다** — 아직 다 정하지 않은 중간 상태를 저장해두고 나중에 이어서 할 수 있어야 하기 때문이다.

## Consequences
- 100%를 넘는 상태로는 "완료"가 물리적으로 불가능해서, 서버에 잘못된(불가능한) 목표 비중 합계가 저장되는 경우가 원천적으로 없다.
- 이 검증은 `draftGroups`(로컬 draft) 기준으로 매 렌더마다 계산되며, 서버에 저장된 값이 아니라 편집 중인 값을 즉시 반영한다.
- 100% 미만 상태에 대한 검증/차단은 여전히 없다 — 자산군 배분과 종목 배분이 둘 다 진행 중인 초안 상태로 여러 번에 걸쳐 저장하는 것을 허용한다는 기존 방침(ADR-0007)과 일관된다.
